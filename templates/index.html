🤖 AI Import - Ako to funguje?

  1. Odfotiť alebo nahrať fotku s otázkami
  2. Obrázok sa automaticky predspracuje (ostrosť, kontrast, jas)
  3. AI (GPT-4o) analyzuje obrázok a rozpozná:
    • Text otázok a odpovedí
    • Zakrúžkované odpovede
    • Podčiarknutý, tučný alebo zvýraznený text
    • Checkmarky a hviezdičky
  4. Skontrolujete a upravíte výsledok
  5. Uložíte ako nový test alebo pridáte k existujúcemu

💡 Tipy na lepšie výsledky

  • Urobte ostrú fotografiu s dobrým osvetlením
  • Správne odpovede jasne zakrúžkujte alebo podčiarknite
  • Text by mal byť čitateľný a nezmazaný
  • Vyhnite sa tieňom a odleskom

📖 Návod na použitie

🤖 Nahranie testov cez AI

  1. Kliknite "🤖 AI Import"
  2. Nahrajte fotografiu otázok (môžete aj viac strán naraz)
  3. Voliteľne zapnite "🔬 Pokročilé predspracovanie" pre lepšie rozpoznávanie špatných fotiek
  4. Kliknite "✨ Spracovať s AI" (trvá ~ 1 minúta na stránku)
  5. ⚠️ DÔLEŽITÉ: Skontrolujte správne odpovede pri každej otázke - AI ich nevie určiť na 100%
  6. Zadajte názov testu a vyberte či vytvoriť nový alebo pridať k existujúcemu
  7. Kliknite "💾 Uložiť test"

💡 Tipy:

  • Robte ostré fotky s dobrým osvetlením
  • Pri viacerých stranách sa každá analyzuje samostatne
  • Otázky zo strán sa automaticky zoskupia

✏️ Úprava existujúcich testov

  1. V zozname testov kliknite na "✏️ Upraviť" pri teste
  2. Upravte otázky, odpovede alebo správne odpovede
  3. Zmeny sa automaticky ukladajú
  4. Kliknite "Späť" pre návrat na zoznam

🎯 Testovanie

  1. Kliknite na test v zozname
  2. Nastavte parametre:
    • Časový limit: 20/30/60 min alebo bez limitu
    • Rozsah: Napr. 1-50 (časť testu)
    • Poradie: Po poradí / Zamixované
    • Odpovede: Po každej otázke / Na konci / Opakovať nesprávne
  3. Spustite: "Spustiť test" (hodnotenie) alebo "Režim učenia" (bez tlaku)
  4. Po teste vidíte výsledky a štatistiky

⭐ Ďalšie funkcie

  • Viacero testov naraz: Zaškrtnite checkboxy → "Spustiť vybrané testy"
  • Štatistiky: Počet absolvovaní, posledný výsledok a priemer pri každom teste
  • Režim učenia: Všetky otázky so správnymi odpoveďami bez hodnotenia

📖 Príklad formátu testov

Formát JSON súboru

Vytvorte JSON súbor v priečinku testy/ s nasledujúcim formátom:

Jednoduchý príklad:

[
  {
    "title": "Názov testu",
    "description": "Popis testu",
    "questions": [
      {
        "question": "Otázka s jednou správnou odpoveďou?",
        "answers": [
          "Odpoveď 1",
          "Odpoveď 2",
          "Odpoveď 3",
          "Odpoveď 4"
        ],
        "correct": 0
      },
      {
        "question": "Otázka s viacerými správnymi odpoveďami?",
        "answers": [
          "Odpoveď A",
          "Odpoveď B",
          "Odpoveď C",
          "Odpoveď D"
        ],
        "correct": [0, 2]
      }
    ]
  }
]

Dôležité pravidlá:

  • correct: Index správnej odpovede (0 = prvá, 1 = druhá, atď.)
  • Jedna odpoveď: "correct": 0 (číslo)
  • Viac odpovedí: "correct": [0, 2] (pole čísel)
  • title a description: Sú voliteľné
  • Môžete mať: Jeden test { ... } alebo viacero testov [ {...}, {...} ]

Ako vytvoriť súbor:

1. Vytvorte súbor: testy/moj_test.json
2. Skopírujte vyššie uvedený formát
3. Upravte otázky a odpovede
4. Obnovte stránku - test sa automaticky načíta
