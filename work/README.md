# Rozpracovaná práca a nové podklady

Sem vkladajte PDF, fotografie, poznámky, návrhy JSON a ďalšie súbory pred spracovaním. Môžu ležať priamo tu; podpriečinok podľa úlohy vytvorte až vtedy, keď pomôže prehľadnosti, napríklad `work/biochemia/`.

AI stačí zadať napríklad: „Spracuj nové podklady vo work pre biochémiu v 2. ročníku.“ Rozpracované výsledky ukladajte sem. Aplikácia tento priečinok nenačítava a vloženie súboru nespustí import ani platené AI volanie.

Po dokončení patria overené testy do dát aplikácie, trvalo používané importné pravidlá do `tools/imports/` a uchované originály do `sources/`. Presun vykonajte ako súčasť konkrétnej úlohy, bez prepísania existujúcich súborov; postup ochrany dát je v [AGENTS.md](../AGENTS.md). Samotné uloženie sem nie je pokyn na zmenu hotových testov alebo nasadenie.

Obsah okrem tohto návodu je **mimo Gitu a Docker image**. Pri zálohe alebo presune pracovného prostredia skopírujte aj celý `work/`. Rozpracované súbory sa pri upratovaní nemažú; nie sú to cache.
